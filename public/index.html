Safe self-check

Default target is your current egress IP (as seen by Cloudflare) — no input needed. We check Ollama (11434), Ray (8265) and Jupyter (8888). Every probe is a read-only GET against a version, health or listing endpoint — no pull, no generate, no job submission, no path traversal. Strict rate limits apply. Defensive checklist

  • Network isolationBind Ollama to 127.0.0.1 or a private VPC. Never 0.0.0.0 on the public internet.
  • AuthenticationPut a reverse proxy (TLS + API key / mTLS) in front. Do not rely on “security through obscurity.”
  • Input validationReject model names with path traversal, URLs, or absolute filesystem paths.
  • Least privilegeNon-root container, read-only rootfs where possible, no access to cloud metadata.
  • DetectAlert on /api/pull spikes and model names containing ../, /etc, or link-local metadata IPs.

Methodology & ethics

LeakyCompute is a defensive research project. The public surface does not mass-scan the internet and does not ship exploit payloads. Researchers request GitHub-SSO lab access via issue; approval writes an allowlist entry used by the gated lab.
